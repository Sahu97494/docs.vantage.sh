## Opening Issues

If you encounter any docs issues or have suggestions for improvement, please open a GitHub issue. 

## Development

Install the [Mintlify CLI](https://www.npmjs.com/package/mint) to preview your documentation changes locally. To install, use the following command:

```
npm i -g mint
```

Open a new branch, add you changes, and run the following command at `/docs/mintlify-migration`, where the `docs.json` file is located:

```
mint dev
```

View your local preview at `http://localhost:3000`.

Open a pull request with your changes.
